# Site MVP marciodev.com Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publicar em `marciodev.com` o site estático com home, 4 case studies, card do Observatório, "Outros projetos" vindos do GitHub e temas harmônicos espelhados.

**Architecture:** Astro gera HTML estático; projetos são uma content collection em Markdown validada por schema; a paleta vive num único módulo TypeScript que gera as variáveis CSS e é testado por contraste. Repositórios do GitHub são buscados no build com fallback em JSON versionado. Cloudflare Pages faz build e deploy a cada push.

**Tech Stack:** Node 22, Astro 7.4, Tailwind CSS 4.3 (`@tailwindcss/vite`), `@astrojs/sitemap` 3.7, `@fontsource/{space-grotesk,inter,jetbrains-mono}`, Vitest 5, Playwright 1.64 + `@axe-core/playwright` 4.14, `@lhci/cli` 0.15.

**Spec:** `docs/spec.md`

## Global Constraints

- Idioma do conteúdo: pt-BR; `<html lang="pt-BR">`; estrutura de rotas permite `/en/` depois (nenhum texto fixo fora de `src/i18n/pt.ts`).
- Nunca usar "full-stack"; nunca usar verde; tom em primeira pessoa.
- Cores só via variáveis CSS geradas de `src/design/palette.ts`; nenhum hex solto em componentes.
- Contraste: texto ≥ 4.5:1, anel de foco ≥ 3:1, em ambos os temas.
- Zero JavaScript de framework no cliente; único script inline permitido: tema (anti-flash) e o toggle.
- Lighthouse celular: performance ≥ 0.95, acessibilidade ≥ 0.95, SEO ≥ 0.95.
- Layout sem rolagem horizontal em 360, 768 e 1440 px.
- Animações desligadas sob `prefers-reduced-motion: reduce`.
- Contato público: `contactmarcioflima@gmail.com`, `https://github.com/MarcioFerreiraL`, `https://www.linkedin.com/in/marcioflima/`. Sem telefone, sem e-mail UPE.
- `site: "https://marciodev.com"` no `astro.config.mjs`.

## Review Focus

1. API do GitHub fora do ar ou com rate limit (60 req/h sem token) no build → build não falha; usa `src/data/repos-fallback.json`. (Task 4)
2. Visitante com tema do sistema escuro e nenhuma escolha salva, ou com `localStorage` bloqueado → tema correto sem flash e sem erro no console. (Task 2)
3. Título longo de projeto ou muitas tags em 360 px → quebra de linha, sem rolagem horizontal. (Task 8)
4. Acesso direto a `/projetos/observatorio-upe` → 404 (o card não tem página). (Task 6)
5. Navegação só por teclado → foco visível no toggle de tema, cards e botões de currículo em ambos os temas. (Task 8)
